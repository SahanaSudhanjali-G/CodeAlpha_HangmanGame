# CodeAlpha Hangman Game

## Project Description

This project is a simple text-based Hangman game developed using Python.

The player has to guess a randomly selected word one letter at a time. The player is allowed a maximum of 6 incorrect guesses.

## Features

- Randomly selects a word from 5 predefined words
- Allows the player to guess one letter at a time
- Displays correctly guessed letters
- Tracks incorrect guesses
- Allows a maximum of 6 incorrect guesses
- Detects repeated guesses
- Validates user input
- Displays winning and game-over messages

## Technologies Used

- Python
- Random module
- Lists
- Strings
- While loop
- For loop
- If-else statements
- Console input/output
